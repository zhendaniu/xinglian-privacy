# 隐私政策 **生效日期：2026 年 9 月 19 日** **最后更新：2026 年 9 月 19 日** 欢迎使用「星链 AI agent」小程序（以下简称“本小程序”）。我们非常重视用户的隐私保护，本隐私政策将向您说明我们如何收集、存储、使用和共享您的个人信息，以及您享有的权利。请您仔细阅读本政策后再使用本服务。 --- ## 一、我们如何收集和使用您的个人信息 ### 1.1 我们收集的个人信息类型 为了提供正常服务，我们需要收集以下类型的信息： #### （1）账号信息 - **微信头像与昵称**：用于展示您的用户资料，不会用于其他用途。 - **手机号**：仅在兑换标准/尊享会员时通过微信官方组件获取，用于身份验证与会员权益绑定。**我们不存储明文手机号**，仅保存脱敏后的标识符。 - **OpenID/UnionID**：用于唯一识别用户身份，实现跨门店档案同步。 #### （2）设备信息 - **平台类型**（iOS/Android）、**屏幕尺寸**、**系统版本**：用于适配不同设备的显示效果。 - **网络状态**：判断当前是 Wi-Fi 还是移动网络，优化视频加载体验。 #### （3）业务数据 - **文案内容**：您输入的标题、描述等，用于 AI 生成短视频脚本。 - **视频素材**：您上传的图片、视频文件，用于数字人口型合成或素材混剪。 - **算力消耗记录**：每次生成任务消耗的算力点数，用于账户余额管理。 - **会员有效期**：您的会员档位与到期时间，用于权限控制。 #### （4）日志信息 - **操作日志**：包括访问时间、接口调用次数、错误码等，用于故障排查与性能优化。 - **崩溃报告**：当小程序异常退出时，自动上报错误堆栈（不包含任何个人身份信息）。 ### 1.2 我们如何使用您的个人信息 我们收集的信息仅用于以下目的： | 信息类型 | 使用目的 | 是否必需 | |---------|---------|---------| | 头像/昵称 | 展示用户资料 | 否（可匿名使用） | | 手机号 | 会员权益激活 | 是（仅限标准/尊享档） | | OpenID/UnionID | 用户身份识别 | 是（核心功能必需） | | 文案/素材 | AI 内容生成 | 是（业务功能必需） | | 设备信息 | UI 适配优化 | 否（可选） | | 日志信息 | 故障排查 | 是（安全合规必需） | ### 1.3 我们不会主动收集的信息 以下信息**不会**被我们收集： - 微信聊天记录、朋友圈内容 - 通讯录、短信、通话记录 - 地理位置信息（除非您主动授权） - 银行卡号、支付密码等金融信息 --- ## 二、我们如何使用 Cookie 和同类技术 本小程序**不使用 Cookie**或其他本地存储技术来追踪用户行为。 我们仅使用微信官方提供的 `Storage` API 存储必要的会话 token（如 `authToken`），该 token 在登录态过期后自动失效（最长 30 天）。 --- ## 三、我们如何共享、转让、公开披露您的个人信息 ### 3.1 我们不会共享您的个人信息 除非获得您的明确同意，否则我们不会向任何第三方共享您的个人信息。 ### 3.2 我们会与合作伙伴共享的最低限度信息 为提供服务，我们可能与以下类型的合作伙伴共享必要信息： | 合作方 | 共享信息 | 目的 | 安全措施 | |-------|---------|------|---------| | **腾讯云 COS** | 上传的视频/图片文件 | 对象存储 | 加密传输 + 访问控制 | | **阿里百炼（CosyVoice）** | 文本转语音的输入内容 | TTS 服务 | 端到端加密 | | **DeepSeek** | 文案生成的 prompt | LLM 推理 | 仅传输必要字段 | | **奇云 API** | 抖音视频链接解析 | 素材提取 | HTTPS 签名验证 | 以上合作方均通过 ISO 27001 认证，且签署数据保护协议（DPA）。 ### 3.3 我们不会公开披露您的个人信息 除非法律法规要求或政府主管部门强制要求，否则我们不会公开披露您的个人信息。 --- ## 四、我们如何保护你的个人信息 ### 4.1 技术防护措施 - **数据传输加密**：全站采用 HTTPS（TLS 1.3），防止中间人攻击。 - **敏感数据存储加密**：密码、token 等采用 HMAC-SHA256 签名，密钥独立管理。 - **数据库访问控制**：PostgreSQL 实例部署在 VPC 内网，仅允许特定 IP 访问。 - **定期安全审计**：每季度进行一次渗透测试与代码审查。 - **防 SQL 注入**：所有数据库查询使用 Prisma ORM 参数化，杜绝拼接风险。 - **防重放攻击**：卡密兑换事务内原子校验，同一张卡只能成功一次。 ### 4.2 管理制度保障 - **最小权限原则**：员工仅能访问其职责范围内的数据。 - **操作审计日志**：所有后台操作记录操作人、时间、IP，保留 180 天。 - **应急响应机制**：发生数据泄露时，24 小时内通知用户并向监管部门报告。 --- ## 五、您的权利 根据《个人信息保护法》，您享有以下权利： ### 5.1 访问权 您可以查看自己存储的头像、昵称、会员档位等信息（路径：个人中心 → 个人资料）。 ### 5.2 更正权 发现信息有误时，可通过客服申请修改（路径：会员中心 → 咨询客服）。 ### 5.3 删除权 您可以申请删除自己的账号及所有关联数据（路径：会员中心 → 注销账号）。 **注意**：删除后无法恢复，请谨慎操作。 ### 5.4 撤回同意权 您可以通过以下方式撤回授权： - 关闭微信的「获取手机号」权限 - 清除小程序缓存（设置 → 通用 → 存储空间 → 清理） --- ## 六、未成年人保护 本小程序**不面向未满 14 周岁的未成年人**。若您是不适龄用户，请立即停止使用并联系我们删除相关数据。 --- ## 七、政策更新 我们可能不定期更新本隐私政策，更新后将通过以下方式通知您： 1. 小程序首页公告栏弹窗 2. 推送消息（需您已授权） 3. 官方网站公示 **重大变更**（如新增收集类型、改变使用目的）将至少提前 7 天通知您，并征得您的重新同意。 --- ## 八、联系我们 如您对本隐私政策有任何疑问、投诉或建议，请通过以下方式联系我们： | 联系方式 | 说明 | |---------|------| | **微信客服** | 打开小程序 → 会员中心 → 点击「咨询客服」按钮 | | **邮箱** | support@rongkai.ai（工作日 24 小时内回复） | | **投诉举报** | 开放平台后台留言（需提供违规证据） | 我们将于收到反馈后 15 个工作日内处理完毕。 --- ## 九、适用法律与争议解决 本隐私政策的解释与执行适用中华人民共和国法律。 因本政策引起的任何争议，双方应友好协商解决；协商不成的，提交**深圳市南山区人民法院**管辖。 --- **星链 AI agent 运营团队** 2026 年 9 月 19 日 --- ## 附录：术语表 | 术语 | 定义 | |-----|------| | **OpenID** | 微信为用户分配的唯一年度标识符，不同小程序下同一用户可能得到不同的 OpenID | | **UnionID** | 微信为用户分配的全局唯一标识符，同一主体下的多个小程序共享 UnionID | | **HMAC-SHA256** | 一种基于哈希的消息认证码算法，用于验证数据完整性与来源真实性 | | **VPC** | 虚拟私有云，腾讯云上隔离的网络环境，增强数据安全 | --- **使用说明：** 1. 将本文件保存为 `privacy-policy.md` 2. 部署到任意 HTTPS 站点（如 GitHub Pages、Vercel、自有服务器） 3. 获取可公开访问的链接（例如：https://yourdomain.com/privacy-policy） 4. 在微信开放平台后台填写该链接并提交审核 **推荐部署方式（GitHub Pages）：** ```bash # 1) 创建仓库 git init privacy-policy cd privacy-policy echo "# Privacy Policy" > README.md # 2) 上传政策文档 cp ../starlink-release/docs/privacy-policy.md index.html # 3) 启用 GitHub Pages # Settings → Pages → Source: main branch → Save # 4) 复制生成的 HTTPS 链接（格式：https://username.github.io/privacy-policy/） ``` 需要我帮你调整某些条款的细节吗？比如添加具体的客服邮箱、修改管辖法院等。
